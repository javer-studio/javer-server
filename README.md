# Javer Server (PvP Fixed): bug reports

**Javer Server (PvP Fixed)** is a free, open source (GPL-3.0) preview fork of the [Pumpkin](https://github.com/Pumpkin-MC/Pumpkin) Minecraft server, made to match
vanilla Minecraft Java 26.3 PvP exactly: knockback, shields, totems, bows, wind charges, the mace and more.

This page is only for **bug reports and feature requests**. The program and its source code live on our website:

- Project page, test results and downloads: https://javerstudios.com/javer-server.html
- Files: https://downloads.javerstudios.com/javer-server/

It is a **preview**. Bugs are expected, and we fix them in the open. Please report what you find.

## How to report a bug

1. Click **Issues** → **New issue** → **Bug report**.
2. Tell us what you did, what you expected, and what happened. For PvP bugs, the exact steps matter most
   (what you held, whether you were sprinting, what you swapped to, which way you were looking).
3. Say which version you run (the first line of the server log) and whether you play Java 26.3.

Please do not post passwords, tokens or personal data.

## Security problems

Do not open a public issue. Email studio@javer.pro with the details.
